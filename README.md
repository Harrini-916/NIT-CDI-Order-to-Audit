
# NIT-CDI Order-to-Audit Management System

## Project Overview

A web-based Order-to-Audit Management System designed for a small-scale South Indian snacks manufacturing business.

The application integrates sales, inventory, production, GST billing, product costing and financial reporting into one centralized platform.

## Technology Stack

- Frontend: React.js
- Styling: Tailwind CSS
- Backend: Python FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- Version Control: Git and GitHub
- Deployment: Docker

## Main Modules

1. Authentication and Role Management
2. Sales and Order Management
3. Inventory Management
4. BOM and Production Management
5. GST Billing
6. Product Costing
7. Reports and Auditing
